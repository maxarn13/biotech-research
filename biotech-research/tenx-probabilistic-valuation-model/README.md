TENX Probabilistic Valuation Model

A quantitative biotech valuation framework for Tenax Therapeutics (TENX) including:

- Monte Carlo simulation
- Bayesian posterior updating
- Clinical trial endpoint probability analysis
- Risk-adjusted valuation modeling
- Scenario forecasting

This workbook builds a bottom-up, probability-weighted valuation of TNX-103 — Tenax's levosimendan-based therapy for pulmonary hypertension with heart failure with preserved ejection fraction (PH-HFpEF). The core question it answers: *What is TNX-103 worth today, given the clinical uncertainty?*
